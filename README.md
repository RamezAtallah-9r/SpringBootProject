# 🩺 LifeBeacon

**LifeBeacon** is an AI-powered health and nutrition platform built with **Java Spring Boot**. It helps users manage their health through personalized nutrition plans, body tracking, AI-powered recommendations, and collaborative meal planning.

---

## 🚀 Tech Stack

- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA (Hibernate)
- JSP
- JSTL
- Tailwind CSS
- JavaScript
- MySQL
- Maven

---

## ✨ Features

- User Authentication
- Health Onboarding
- Personalized Dashboard
- InBody Tracking
- AI Meal Recommendations
- MealCircle
- Profile Management
- Email Verification
- Responsive UI
