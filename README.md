# SpringBootProject
---

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/LifeBeacon.git
```

### 2. Navigate to the project

```bash
cd LifeBeacon
```

### 3. Run the project

Run the application using your IDE or with Maven:

```bash
mvn spring-boot:run
```
